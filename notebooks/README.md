The notebook in this directory contains the current FYDP training and evaluation workflow for the hybrid CNN-GNN blood-cell analysis project.

The raw dataset and trained model checkpoints are intentionally not included in this public repository. See `data/README.md`, `models/README.md`, and the root `README.md` for setup notes and the current evaluation-status disclaimer.

This notebook is an academic project artifact, not a clinically validated diagnostic system.
